# 在线音乐播放器系统 - 需求分析文档

## 1. 项目概述

### 1.1 项目背景
本项目旨在开发一个基于 Spring Boot 的在线音乐播放器系统，为用户提供流畅的音乐播放体验，同时为管理员提供便捷的资源管理平台。

### 1.2 项目目标
- 为用户提供高质量的在线音乐播放服务
- 支持歌手、歌曲、歌单的多维度浏览和搜索
- 为管理员提供完善的内容管理和数据统计功能
- 构建安全、稳定、可扩展的音乐平台

### 1.3 技术架构
- **架构模式**: B/S（Browser/Server）架构
- **后端技术**: Java + Spring Boot 2.7 + MyBatis-Plus
- **数据库**: MySQL 8.0
- **前端技术**: Vue.js / HTML5 + CSS3 + jQuery
- **文件存储**: 本地磁盘 / MinIO / 阿里云 OSS
- **开发工具**: IntelliJ IDEA + Postman + Git

## 2. 系统角色分析

### 2.1 角色定义

#### 2.1.1 管理员（Admin）
**角色描述**: 平台运营管理人员，负责内容审核、资源管理和数据监控

**权限范围**:
- 登录后台管理系统
- 查看平台运营数据统计
- 管理用户账号（查看、禁用、启用）
- 管理歌手信息（增删改查）
- 管理歌曲资源（上传、编辑、删除）
- 管理歌单内容（创建、编辑、删除）
- 上传文件（音频、歌词、图片）

#### 2.1.2 普通用户（User）
**角色描述**: 音乐听众，使用平台进行音乐播放和资源浏览

**权限范围**:
- 注册和登录账号
- 浏览歌手、歌曲、歌单
- 搜索音乐资源
- 播放音乐
- 收藏歌曲和歌单
- 创建个人歌单
- 修改个人信息

### 2.2 角色交互关系
```
管理员 ──创建──> 歌手档案
管理员 ──上传──> 歌曲文件
管理员 ──创建──> 官方歌单
管理员 ──管理──> 用户账号

用户 ──浏览──> 歌手/歌曲/歌单
用户 ──收藏──> 歌曲/歌单
用户 ──创建──> 个人歌单
用户 ──播放──> 歌曲
```

## 3. 功能需求分析

### 3.1 管理员端功能需求

#### 3.1.1 登录系统
**功能描述**: 提供安全的管理员身份认证入口

**功能需求**:
- FR-A-001: 管理员使用账号和密码登录后台系统
- FR-A-002: 密码采用 BCrypt 加密存储
- FR-A-003: 登录失败时显示错误提示
- FR-A-004: 登录成功后生成身份令牌（JWT/Session）
- FR-A-005: 支持登出功能，清除身份令牌

**业务规则**:
- 连续登录失败 5 次后锁定账号 30 分钟
- 登录令牌有效期为 24 小时

#### 3.1.2 数据统计模块
**功能描述**: 集中展示平台运营核心数据

**功能需求**:
- FR-A-006: 显示注册用户总数
- FR-A-007: 显示入驻歌手总数
- FR-A-008: 显示创建歌单总数
- FR-A-009: 显示今日平台活跃用户数
- FR-A-010: 数据实时更新或定时刷新

**统计指标**:
- 用户总数：所有注册用户数量
- 歌手总数：平台入驻的歌手数量
- 歌单总数：官方歌单 + 用户创建歌单
- 今日活跃度：当日登录或播放音乐的用户数

#### 3.1.3 用户管理模块
**功能描述**: 管理平台注册用户，维护社区秩序

**功能需求**:
- FR-A-011: 查看所有注册用户列表
- FR-A-012: 查看用户详细信息（昵称、手机号/邮箱、注册时间、状态）
- FR-A-013: 禁用用户账号（违规用户）
- FR-A-014: 启用已禁用的用户账号
- FR-A-015: 支持按用户名、手机号、邮箱搜索用户
- FR-A-016: 用户列表支持分页显示

**业务规则**:
- 被禁用的用户无法登录系统
- 禁用操作需记录操作人和操作时间

#### 3.1.4 歌单管理模块
**功能描述**: 创建和管理官方推荐歌单

**功能需求**:
- FR-A-017: 创建新歌单（输入歌单名称、描述、风格标签）
- FR-A-018: 上传歌单封面图片
- FR-A-019: 编辑歌单信息
- FR-A-020: 删除歌单
- FR-A-021: 向歌单中添加歌曲
- FR-A-022: 从歌单中移除歌曲
- FR-A-023: 调整歌单内歌曲顺序
- FR-A-024: 查看歌单列表（支持分页）

**业务规则**:
- 歌单名称不能为空，长度限制 50 字符
- 封面图片格式支持 JPG/PNG，大小不超过 2MB
- 删除歌单不会删除歌曲本身

#### 3.1.5 歌手管理模块
**功能描述**: 维护歌手档案和音乐资源

**功能需求**:
- FR-A-025: 创建歌手档案（姓名、外文名、流派、简介）
- FR-A-026: 上传歌手头像照片
- FR-A-027: 编辑歌手信息
- FR-A-028: 删除歌手档案
- FR-A-029: 在歌手名下上传音乐文件（MP3/FLAC）
- FR-A-030: 上传歌词文件（LRC 格式）
- FR-A-031: 编辑歌曲信息（歌曲名、专辑名、发行时间）
- FR-A-032: 删除歌曲
- FR-A-033: 查看歌手列表（支持分页和搜索）

**业务规则**:
- 歌手姓名不能为空
- 音频文件格式支持 MP3、FLAC
- 歌词文件格式为 LRC
- 删除歌手时需确认是否同时删除其下所有歌曲
- 建立"歌手-专辑-歌曲"的层级关系

### 3.2 用户端功能需求

#### 3.2.1 身份验证
**功能描述**: 用户注册和登录功能

**功能需求**:
- FR-U-001: 用户通过手机号注册账号
- FR-U-002: 用户通过邮箱注册账号
- FR-U-003: 注册时设置密码（长度 6-20 位）
- FR-U-004: 用户使用手机号/邮箱 + 密码登录
- FR-U-005: 登录成功后生成身份令牌
- FR-U-006: 支持登出功能
- FR-U-007: 密码采用 BCrypt 加密存储

**业务规则**:
- 手机号和邮箱不能重复注册
- 密码需包含字母和数字
- 登录令牌有效期为 7 天

#### 3.2.2 歌手浏览
**功能描述**: 多维度浏览和查看歌手信息

**功能需求**:
- FR-U-008: 按首字母（A-Z）浏览歌手列表
- FR-U-009: 按语种（华语、欧美、日韩）筛选歌手
- FR-U-010: 按流派（流行、摇滚、民谣等）筛选歌手
- FR-U-011: 点击歌手进入歌手主页
- FR-U-012: 歌手主页显示个人简介
- FR-U-013: 歌手主页显示热门歌曲列表
- FR-U-014: 歌手主页显示发行的专辑信息
- FR-U-015: 歌手列表支持分页加载

**展示内容**:
- 歌手头像、姓名、外文名
- 个人简介
- 热门歌曲（按播放量排序）
- 专辑列表

#### 3.2.3 歌单浏览
**功能描述**: 浏览和收藏歌单

**功能需求**:
- FR-U-016: 首页展示精选歌单
- FR-U-017: 按风格标签筛选歌单
- FR-U-018: 点击歌单查看歌单详情
- FR-U-019: 歌单详情页显示歌曲列表
- FR-U-020: 一键播放整个歌单
- FR-U-021: 收藏歌单到个人收藏
- FR-U-022: 取消收藏歌单
- FR-U-023: 歌单列表支持分页加载

**展示内容**:
- 歌单封面、名称、描述
- 创建者信息
- 歌曲数量
- 收藏数量

#### 3.2.4 搜索与分类
**功能描述**: 快速检索音乐资源

**功能需求**:
- FR-U-024: 顶部搜索框输入关键词
- FR-U-025: 按歌曲名称模糊搜索
- FR-U-026: 按歌手姓名模糊搜索
- FR-U-027: 按专辑名称模糊搜索
- FR-U-028: 搜索结果分类显示（歌曲、歌手、专辑）
- FR-U-029: 点击搜索结果跳转到详情页
- FR-U-030: 搜索历史记录（可选）

**业务规则**:
- 搜索关键词长度至少 2 个字符
- 搜索结果按相关度排序

#### 3.2.5 音乐播放器
**功能描述**: 核心音乐播放功能

**功能需求**:
- FR-U-031: 播放/暂停音乐
- FR-U-032: 上一首/下一首切换
- FR-U-033: 音量调节（0-100%）
- FR-U-034: 播放进度条显示
- FR-U-035: 拖拽进度条跳转播放位置
- FR-U-036: 单曲循环模式
- FR-U-037: 列表循环模式
- FR-U-038: 随机播放模式
- FR-U-039: 显示当前播放歌曲信息（封面、歌名、歌手）
- FR-U-040: 显示歌词（LRC 格式解析）
- FR-U-041: 歌词滚动同步
- FR-U-042: 播放列表管理

**播放模式**:
- 单曲循环：当前歌曲循环播放
- 列表循环：播放列表循环播放
- 随机播放：随机顺序播放列表中的歌曲

#### 3.2.6 个人中心
**功能描述**: 用户个人信息和收藏管理

**功能需求**:
- FR-U-043: 修改个人昵称
- FR-U-044: 上传/修改头像
- FR-U-045: 修改个性签名
- FR-U-046: 修改登录密码
- FR-U-047: 查看"我喜欢的音乐"（收藏的歌曲）
- FR-U-048: 查看"我创建的歌单"
- FR-U-049: 创建新歌单
- FR-U-050: 编辑自己创建的歌单
- FR-U-051: 删除自己创建的歌单
- FR-U-052: 向自己的歌单添加歌曲
- FR-U-053: 从自己的歌单移除歌曲

**业务规则**:
- 昵称长度限制 20 字符
- 头像格式支持 JPG/PNG，大小不超过 1MB
- 修改密码需验证原密码

## 4. 非功能性需求

### 4.1 性能需求
- NFR-001: 系统支持至少 1000 并发用户在线
- NFR-002: 页面响应时间不超过 2 秒
- NFR-003: 音乐播放延迟不超过 1 秒
- NFR-004: 数据库查询响应时间不超过 500ms
- NFR-005: 文件上传速度不低于 1MB/s

### 4.2 安全需求
- NFR-006: 用户密码采用 BCrypt 加密存储
- NFR-007: 使用 JWT 或 Session 进行身份认证
- NFR-008: 敏感接口需验证用户身份和权限
- NFR-009: 防止 SQL 注入攻击
- NFR-010: 防止 XSS 跨站脚本攻击
- NFR-011: 文件上传需验证文件类型和大小
- NFR-012: 接口需进行频率限制，防止恶意请求

### 4.3 可用性需求
- NFR-013: 系统可用性达到 99.5% 以上
- NFR-014: 提供友好的错误提示信息
- NFR-015: 界面操作简单直观，符合用户习惯
- NFR-016: 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- NFR-017: 移动端自适应布局（可选）

### 4.4 可维护性需求
- NFR-018: 代码遵循阿里巴巴 Java 开发规范
- NFR-019: 关键业务逻辑需添加注释
- NFR-020: 提供完整的 API 接口文档
- NFR-021: 数据库表结构需有清晰的注释
- NFR-022: 使用 Git 进行版本控制

### 4.5 扩展性需求
- NFR-023: 支持水平扩展（负载均衡）
- NFR-024: 文件存储支持切换（本地/OSS）
- NFR-025: 数据库支持读写分离（可选）
- NFR-026: 支持 Redis 缓存热点数据（可选）

### 4.6 兼容性需求
- NFR-027: 支持 Windows、macOS、Linux 操作系统
- NFR-028: 支持 MySQL 8.0 及以上版本
- NFR-029: 支持 JDK 1.8 及以上版本

## 9. 业务流程

### 9.1 用户听歌流程
```
用户登录 → 浏览/搜索音乐 → 点击播放 → 播放器加载音频 →
显示歌词 → 播放音乐 → 收藏/添加到歌单
```

### 9.2 管理员上传歌曲流程
```
管理员登录 → 创建/选择歌手 → 上传音频文件 → 上传歌词文件 →
填写歌曲信息 → 保存 → 用户可见
```

### 9.3 用户创建歌单流程
```
用户登录 → 进入个人中心 → 创建新歌单 → 填写歌单信息 →
浏览音乐 → 添加歌曲到歌单 → 保存
```

## 11. 风险分析

### 11.1 技术风险
- **音频流式传输**: 大文件传输可能影响性能，需考虑分片传输或 CDN 加速
- **并发播放**: 高并发场景下服务器压力大，需做好负载均衡和缓存
- **文件存储**: 本地存储容量有限，建议使用 OSS

### 11.2 业务风险
- **版权问题**: 音乐版权需合法授权
- **内容审核**: 需防止违规内容上传

### 11.3 安全风险
- **数据泄露**: 用户信息需加密存储和传输
- **恶意攻击**: 需防范 SQL 注入、XSS 等攻击
