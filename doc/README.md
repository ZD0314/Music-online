## 技术栈

### 后端（Claude 负责）
- **框架**: Spring Boot 2.7
- **持久层**: MyBatis-Plus
- **数据库**: MySQL 8.0
- **认证**: JWT
- **文档**: Swagger/Knife4j

### 前端（Codex 负责）
- **框架**: Vue.js 3.x / HTML5
- **UI**: Element Plus / Bootstrap
- **HTTP**: Axios
- **播放**: HTML5 Audio API

## 功能模块

### 管理员端（5个模块）

1. **登录系统** - 身份认证
2. **数据统计** - 运营数据展示
3. **用户管理** - 用户查看、禁用、启用
4. **歌单管理** - 创建、编辑官方歌单
5. **歌手管理** - 歌手信息、音乐文件管理

### 用户端（6个模块）

1. **身份验证** - 注册、登录
2. **歌手浏览** - 分类浏览歌手
3. **歌单浏览** - 浏览、收藏歌单
4. **搜索功能** - 综合搜索
5. **音乐播放器** - 播放控制、歌词显示
6. **个人中心** - 信息管理、收藏管理

## 注意事项

### 安全
- 密码使用 BCrypt 加密
- 接口使用 JWT 认证
- 防止 SQL 注入和 XSS 攻击
- 文件上传需验证类型和大小

### 性能
- 支持 1000 并发用户
- 页面响应时间 < 2 秒
- 音乐播放延迟 < 1 秒
- 数据库查询 < 500ms

### 兼容性
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 支持响应式布局
- 音频格式支持 MP3/FLAC
- 歌词格式支持 LRC
