# 在线音乐播放器系统 - 功能架构文档

## 1. 系统整体架构

### 1.1 架构模式
本系统采用经典的三层架构模式：

```
┌─────────────────────────────────────────────────────────┐
│                     表现层 (Presentation)                │
│  ┌──────────────────┐         ┌──────────────────┐     │
│  │   管理员端前端    │         │    用户端前端     │     │
│  │   (Vue.js/HTML)  │         │   (Vue.js/HTML)  │     │
│  └──────────────────┘         └──────────────────┘     │
└─────────────────────────────────────────────────────────┘
                          │
                    HTTP/HTTPS (RESTful API)
                          │
┌─────────────────────────────────────────────────────────┐
│                     业务层 (Business)                    │
│  ┌──────────────────────────────────────────────────┐  │
│  │              Spring Boot 应用                     │  │
│  │  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐ │  │
│  │  │Controller│ │Service │ │Security│ │FileUtil│ │  │
│  │  └────────┘  └────────┘  └────────┘  └────────┘ │  │

```

### 1.2 技术栈选型

#### 后端技术栈
- **核心框架**: Spring Boot 2.7.x
- **持久层**: MyBatis-Plus 3.5.x
- **数据库**: MySQL 8.0
- **安全认证**: Spring Security + JWT
- **接口文档**: Knife4j (Swagger)
- **工具库**: Hutool、Lombok
- **文件存储**: 本地存储 / 阿里云 OSS

#### 前端技术栈
- **框架**: Vue.js 3.x / HTML5 + jQuery
- **UI 组件**: Element Plus / Bootstrap
- **HTTP 客户端**: Axios
- **音频播放**: HTML5 Audio API
- **状态管理**: Vuex / Pinia

## 2. 数据库架构设计

### 2.1 数据库表结构

#### 2.1.1 用户表 (user)
```sql
CREATE TABLE `user` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
  `password` VARCHAR(100) NOT NULL COMMENT '密码(BCrypt加密)',
  `nickname` VARCHAR(50) COMMENT '昵称',
  `phone` VARCHAR(20) UNIQUE COMMENT '手机号',
  `email` VARCHAR(100) UNIQUE COMMENT '邮箱',
  `avatar` VARCHAR(255) COMMENT '头像URL',
  `signature` VARCHAR(200) COMMENT '个性签名',
  `status` TINYINT DEFAULT 1 COMMENT '状态: 1-正常 0-禁用',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '注册时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_phone (phone),
  INDEX idx_email (email),
  INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

#### 2.1.2 管理员表 (admin)
```sql
CREATE TABLE `admin` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '管理员ID',
  `username` VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
  `password` VARCHAR(100) NOT NULL COMMENT '密码(BCrypt加密)',
  `nickname` VARCHAR(50) COMMENT '昵称',
  `status` TINYINT DEFAULT 1 COMMENT '状态: 1-正常 0-禁用',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='管理员表';
```

#### 2.1.3 歌手表 (artist)
```sql
CREATE TABLE `artist` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '歌手ID',
  `name` VARCHAR(100) NOT NULL COMMENT '歌手名',
  `name_en` VARCHAR(100) COMMENT '外文名',
  `avatar` VARCHAR(255) COMMENT '头像URL',
  `genre` VARCHAR(50) COMMENT '流派: 流行/摇滚/民谣/说唱/电子/古典',
  `language` VARCHAR(20) COMMENT '语种: 华语/欧美/日韩/其他',
  `initial` CHAR(1) COMMENT '首字母(A-Z)',
  `introduction` TEXT COMMENT '个人简介',
  `status` TINYINT DEFAULT 1 COMMENT '状态: 1-正常 0-下架',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_genre (genre),
  INDEX idx_language (language),
  INDEX idx_initial (initial)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='歌手表';
```

#### 2.1.4 专辑表 (album)
```sql
CREATE TABLE `album` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '专辑ID',
  `name` VARCHAR(100) NOT NULL COMMENT '专辑名',
  `artist_id` BIGINT NOT NULL COMMENT '歌手ID',
  `cover` VARCHAR(255) COMMENT '封面URL',
  `release_date` DATE COMMENT '发行日期',
  `description` TEXT COMMENT '专辑描述',
  `status` TINYINT DEFAULT 1 COMMENT '状态: 1-正常 0-下架',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  FOREIGN KEY (artist_id) REFERENCES artist(id) ON DELETE CASCADE,
  INDEX idx_artist_id (artist_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='专辑表';
```

#### 2.1.5 歌曲表 (song)
```sql
CREATE TABLE `song` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '歌曲ID',
  `name` VARCHAR(100) NOT NULL COMMENT '歌曲名',
  `artist_id` BIGINT NOT NULL COMMENT '歌手ID',
  `album_id` BIGINT COMMENT '专辑ID',
  `cover` VARCHAR(255) COMMENT '封面URL',
  `audio_url` VARCHAR(255) NOT NULL COMMENT '音频文件URL',
  `lyric_url` VARCHAR(255) COMMENT '歌词文件URL',
  `duration` INT COMMENT '时长(秒)',
  `file_size` BIGINT COMMENT '文件大小(字节)',
  `format` VARCHAR(10) COMMENT '格式: MP3/FLAC',
  `play_count` BIGINT DEFAULT 0 COMMENT '播放次数',
  `status` TINYINT DEFAULT 1 COMMENT '状态: 1-正常 0-下架',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  FOREIGN KEY (artist_id) REFERENCES artist(id) ON DELETE CASCADE,
  FOREIGN KEY (album_id) REFERENCES album(id) ON DELETE SET NULL,
  INDEX idx_artist_id (artist_id),
  INDEX idx_album_id (album_id),
  INDEX idx_play_count (play_count)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='歌曲表';
```

#### 2.1.6 歌单表 (playlist)
```sql
CREATE TABLE `playlist` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '歌单ID',
  `name` VARCHAR(100) NOT NULL COMMENT '歌单名',
  `cover` VARCHAR(255) COMMENT '封面URL',
  `description` TEXT COMMENT '描述',
  `creator_id` BIGINT NOT NULL COMMENT '创建者ID',
  `creator_type` TINYINT NOT NULL COMMENT '创建者类型: 1-管理员 2-用户',
  `tags` VARCHAR(200) COMMENT '标签(逗号分隔)',
  `play_count` BIGINT DEFAULT 0 COMMENT '播放次数',
  `collect_count` BIGINT DEFAULT 0 COMMENT '收藏次数',
  `status` TINYINT DEFAULT 1 COMMENT '状态: 1-公开 0-私密',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_creator (creator_id, creator_type),
  INDEX idx_play_count (play_count)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='歌单表';
```

#### 2.1.7 歌单-歌曲关联表 (playlist_song)
```sql
CREATE TABLE `playlist_song` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT 'ID',
  `playlist_id` BIGINT NOT NULL COMMENT '歌单ID',
  `song_id` BIGINT NOT NULL COMMENT '歌曲ID',
  `sort_order` INT DEFAULT 0 COMMENT '排序序号',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '添加时间',
  FOREIGN KEY (playlist_id) REFERENCES playlist(id) ON DELETE CASCADE,
  FOREIGN KEY (song_id) REFERENCES song(id) ON DELETE CASCADE,
  UNIQUE KEY uk_playlist_song (playlist_id, song_id),
  INDEX idx_playlist_id (playlist_id),
  INDEX idx_song_id (song_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='歌单-歌曲关联表';
```

#### 2.1.8 收藏表 (favorite)
```sql
CREATE TABLE `favorite` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT 'ID',
  `user_id` BIGINT NOT NULL COMMENT '用户ID',
  `target_id` BIGINT NOT NULL COMMENT '目标ID',
  `target_type` TINYINT NOT NULL COMMENT '目标类型: 1-歌曲 2-歌单',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '收藏时间',
  FOREIGN KEY (user_id) REFERENCES user(id) ON DELETE CASCADE,
  UNIQUE KEY uk_user_target (user_id, target_id, target_type),
  INDEX idx_user_id (user_id),
  INDEX idx_target (target_id, target_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='收藏表';
```

### 3.2 核心模块说明

#### 3.2.1 认证授权模块
- **功能**: 用户/管理员登录、注册、Token 生成和验证
- **技术**: JWT + Spring Security
- **流程**:
  1. 用户提交账号密码
  2. 验证账号密码（BCrypt）
  3. 生成 JWT Token
  4. 后续请求携带 Token 验证身份

#### 3.2.2 用户管理模块
- **功能**: 用户信息管理、状态控制
- **接口**: 查询用户列表、禁用/启用用户、修改用户信息

#### 3.2.3 歌手管理模块
- **功能**: 歌手信息维护、分类筛选
- **接口**: 增删改查歌手、按首字母/语种/流派筛选

#### 3.2.4 歌曲管理模块
- **功能**: 歌曲上传、信息编辑、播放统计
- **接口**: 上传音频/歌词、编辑歌曲信息、删除歌曲、播放计数

#### 3.2.5 歌单管理模块
- **功能**: 歌单创建、歌曲管理、收藏统计
- **接口**: 创建/编辑/删除歌单、添加/移除歌曲、调整顺序

#### 3.2.6 搜索模块
- **功能**: 综合搜索歌曲、歌手、专辑
- **技术**: MySQL LIKE 模糊查询（后期可升级为 Elasticsearch）

#### 3.2.7 文件上传模块
- **功能**: 音频、图片、歌词文件上传
- **技术**: MultipartFile + 本地存储/OSS
- **限制**:
  - 音频: MP3/FLAC，最大 50MB
  - 图片: JPG/PNG，最大 2MB
  - 歌词: LRC，最大 1MB

#### 3.2.8 统计分析模块
- **功能**: 平台数据统计
- **指标**: 用户总数、歌手总数、歌单总数、今日活跃用户

## 5. 接口交互流程

### 5.1 用户听歌完整流程

```
1. 用户登录
   POST /api/user/login
   → 返回 JWT Token

2. 浏览歌单
   GET /api/playlists?page=1&size=20
   → 返回歌单列表

3. 查看歌单详情
   GET /api/playlist/{id}
   → 返回歌单信息和歌曲列表

4. 播放歌曲
   GET /api/song/{id}
   → 返回歌曲详情（包含音频URL）

   GET /api/song/{id}/lyric
   → 返回歌词内容

5. 收藏歌曲
   POST /api/favorite
   Body: {targetId: xxx, targetType: 1}
   → 返回收藏成功
```

### 5.2 管理员上传歌曲流程

```
1. 管理员登录
   POST /api/admin/login
   → 返回 JWT Token

2. 创建/选择歌手
   POST /api/admin/artist
   Body: {name, genre, language, ...}
   → 返回歌手ID

3. 上传音频文件
   POST /api/admin/file/upload
   FormData: {file, type: 'audio'}
   → 返回文件URL

4. 上传歌词文件
   POST /api/admin/file/upload
   FormData: {file, type: 'lyric'}
   → 返回文件URL

5. 创建歌曲记录
   POST /api/admin/song
   Body: {name, artistId, audioUrl, lyricUrl, ...}
   → 返回歌曲ID
```

## 6. 安全架构

### 6.1 认证机制
- **JWT Token**: 有效期 7 天（用户）/ 24 小时（管理员）
- **Token 刷新**: 提供刷新接口延长有效期
- **密码加密**: BCrypt 加密存储

### 6.2 权限控制
- **角色分离**: 管理员和用户接口完全隔离
- **接口鉴权**: 拦截器验证 Token 和角色
- **资源隔离**: 用户只能操作自己的数据

### 6.3 安全防护
- **SQL 注入**: MyBatis 参数化查询
- **XSS 攻击**: 前端输入过滤，后端 HTML 转义
- **CSRF 攻击**: Token 验证
- **文件上传**: 类型和大小验证，文件名随机化
