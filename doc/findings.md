# 项目发现与分析记录

## 项目基本信息
- **项目名称**: 在线音乐播放器
- **架构模式**: B/S 架构
- **后端技术栈**: Spring Boot 2.7 + MyBatis-Plus + MySQL 8.0
- **前端技术栈**: Vue.js / HTML5 + CSS3 + jQuery
- **存储方案**: 本地磁盘 / MinIO / 阿里云 OSS

## 核心业务分析

### 1. 系统角色
- **管理员**: 负责平台数据维护、资源管理、运营监控
- **普通用户**: 音乐听众，使用播放、浏览、搜索、收藏功能

### 2. 核心实体关系
```
用户 (User)
  ├─ 收藏歌曲 (Favorite Songs)
  └─ 创建歌单 (Created Playlists)

歌手 (Artist)
  ├─ 专辑 (Albums)
  └─ 歌曲 (Songs)

歌单 (Playlist)
  └─ 歌曲列表 (Song List)

歌曲 (Song)
  ├─ 音频文件 (Audio File)
  ├─ 歌词文件 (Lyric File)
  └─ 所属歌手/专辑
```

### 3. 关键功能点

#### 管理员端 (5个模块)
1. **登录系统**: BCrypt 加密认证
2. **数据统计**: 用户数、歌手数、歌单数、活跃度
3. **用户管理**: 查看、禁用、封号
4. **歌单管理**: 创建官方歌单、配置封面
5. **歌手管理**: 歌手信息维护、音乐文件上传、歌词管理

#### 用户端 (6个模块)
1. **身份验证**: 手机号/邮箱注册、登录
2. **歌手浏览**: 按首字母/语种/流派分类
3. **歌单浏览**: 精选歌单、风格筛选
4. **搜索功能**: 歌曲/歌手/专辑模糊搜索
5. **音乐播放器**: 播放控制、模式切换（单曲/列表/随机）
6. **个人中心**: 信息修改、收藏管理

### 4. 技术要点

#### 安全性
- 密码加密: BCrypt
- 身份认证: JWT / Session
- 权限控制: 管理员/用户角色分离

#### 文件存储
- 音频格式: MP3 / FLAC
- 歌词格式: LRC
- 图片: 歌手头像、歌单封面
- 存储方案: 本地 / OSS

#### 数据库设计关键点
- 用户表: 支持手机号/邮箱登录
- 歌手表: 姓名、外文名、流派、简介
- 歌曲表: 关联歌手、专辑、文件路径
- 歌单表: 官方/用户创建、歌曲关联
- 收藏表: 用户-歌曲多对多关系

#### 播放器功能
- 播放控制: 播放/暂停、上一首/下一首
- 进度控制: 进度条拖拽
- 音量控制: 音量调节
- 播放模式: 单曲循环、列表循环、随机播放
- 歌词同步: LRC 格式解析

### 6. 技术选型建议
- **认证方式**: JWT（适合前后端分离）
- **文件存储**: 开发阶段使用本地存储，生产环境建议 OSS
- **前端框架**: Vue.js（更现代化，组件化开发）
- **接口规范**: RESTful API
- **文档工具**: Swagger / Knife4j
